
# Dan RNG Autopilot

**Advanced automation for Roblox Dan RNG**

A Windows macro focused on automated progression,
intelligent rebirths, upgrade management and reliability.

## Features

- Automated rebirth and upgrade management
- Configurable rarity targets
- Speed and Luck upgrade prioritisation
- Visual game-state detection
- Discord webhook integration
- Recovery and diagnostic systems

## Installation

1. Download the latest release.
2. Extract the downloaded archive.
3. Run the executable.
4. Configure your settings and start the macro.

## Controls

| Key | Action |
|-----|--------|
| F4 | Start / Stop |
| F5 | Pause / Resume |
| F6 | Debug mode |
| F7 | Diagnostic screenshot |
